# Contributing

Open an issue describing the platform, OS version, expected behavior, and minimal
reproduction. Remove device identifiers, signing identities, real routes, and
personal data from logs before sharing them.

Keep protocol and GPS restoration changes small and add meaningful tests for
changed behavior. Run the unit tests in README.md and build the affected platform.
Device tests must use a device you control, and must end by verifying GPS restoration.

Do not commit firmware, captures, APKs, application bundles, signing keys, or
Xcode user settings. Contributions are provided under GPL-3.0-or-later.
